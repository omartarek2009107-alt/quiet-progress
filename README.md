# Quiet Progress

An all-in-one habit tracker, exam planner, and study countdown app built for seamless productivity.

🚀 **Live Web App:** [https://quiet-progress-web.vercel.app](https://quiet-progress-web.vercel.app)

## Features
- **Habit Tracking:** Set up routines, daily streaks, and customized habit goals.
- **Exam & Countdown Planner:** Keep track of key dates, tests, and study milestones.
- **Cross-Platform Support:** Works seamlessly across desktop and web browsers.
